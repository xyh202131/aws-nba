# 质量验收与实验记录

更新：2026-10-09。本文件合并当前证据与后续验收协议。前端和离线 Agent 已有[实际验收](../docs/AGENT_ACCEPTANCE.md)（20 项测试、真实抽帧、接口和 UI）；真实模型质量、成片与云端尚未验证。本次仅整理文档，未重跑测试。以下建议目标不是官方准确率门槛。

## 同样本比较

对 `train_001`、`train_002` 先制作同一套证据帧及开发者核对记录，再在容量与调用授权具备后比较：Qwen 单模型、Sonnet 单模型、Qwen + Sonnet 复核。争议点才增加 Opus。固定输入集、抽帧策略、字段要求和提示词版本，每次只改变一个主要因素。

不先假定任一模型最好；优先比较错误姓名/官方数值、错认动作、漏检、时序偏差和来源完整性，其次看时延、费用与表达。使用两段训练片调优只能证明这两段上的表现；需要另有未参与调试的合规素材才能补充泛化证据。考试视频的结果独立记录，不回写成赛前成绩。

## 验收门槛与计数

| 项目 | 建议门槛 / 记录方法 | 当前状态 |
| --- | --- | --- |
| 关键事件 | 展示的每条事件有证据；错误动作需删除或修正 | 2 条 AI 视觉核对；无完整事件参考集 |
| 时间定位 | 目标 ±0.5 秒；无可靠参考时写无法评估 | 有出手区间和真实 PTS；抽帧误差 <0.15 秒不是动作识别精度 |
| 身份 | 所有展示姓名、号码、球队有来源；不清楚保留未知 | 两片已有 AI/官方记录核对，独立人工待补 |
| 数字 | 所有展示官方数值可回溯且单位正确 | 41 条公开投篮、2 条视频 xFG；正式数据包仍缺 |
| 事实与推断 | 每条卡片类型明确，不宣称主观意图 | 证据标签已实现，Agent interpretation 可为 null |
| 成片 | 原音/字幕同步，保留纵横比，完整播放；AI 声明可见 | 无成片 |
| 交互 | 播放、跳转、标注开关和证据查看可操作 | 本地已验收，公网及真机未测 |
| 耗时 | 短片端到端目标不超过 10 分钟；记录各阶段实测 | 未测 |
| 成本 | 从实际 usage 和费率计算；包含重试与失败调用 | 未调用 |

有完整人工事件列表时才计算查准率和召回率：先定义事件类型、参与者、时序和 ±0.5 秒容差，预测与参考一对一匹配；重复预测不能重复算对。`precision=TP/(TP+FP)`，`recall=TP/(TP+FN)`；分母为零记 N/A。只有已挑出的三个亮点，没有完整参考事件列表时，报告逐条核对结果，不报召回率。

官方数值来源覆盖率为“带有效原始记录的已展示官方数值数 / 已展示官方数值总数”；总数为零时记 N/A，不写 100%。不要用模型自报置信度代替准确率或概率校准。

## 实验台账

填写[模型实验.csv](%E8%A1%A8%E6%A0%BC/%E6%A8%A1%E5%9E%8B%E5%AE%9E%E9%AA%8C.csv)，一行一个实际模型请求，重试用新 request_id 并关联父请求。保存输入包哈希、提示词版本、模型完整 ID、项目代号/区域、输入/输出/缓存 token、时延、状态和产物引用。不要记录凭据、访问 token、完整项目敏感标识。

CSV 的空表头是准备完成的模板，不是“0 次失败”的统计结果。最终对外报告分开列：开发样例、未调试验证样例、正式考试片；人工/模型复核来源；成功、失败、未执行项目。
