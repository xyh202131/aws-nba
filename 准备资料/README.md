## 第一个可执行任务

**下一任务：基于两条已核对事件制作本地叠字样片。** 读取[实际事件 JSON](../data/processed/20261009/clip-events.json)与[叠字时间草案](../data/processed/20261009/overlay-cues.draft.json)，使用原视频时间定位出手；叠加球员、事件和有来源的 xFG，再核对遮挡、时序和成片。版位、成片导出和音画验收尚未执行。

当前已具备 FFmpeg 实际抽帧能力；中文烧录、编码输出和音频听审仍待验证。不要用旧的“未找到 FFmpeg”记录重装工具。第一项任务的输入、步骤与验收统一见[执行方案 P01](../docs/PROJECT_PLAN.md)。

这些缺口已列出具体获取动作和验收条件，不影响当前资料包完成。当前个人 AWS 设置仍为 `aws-personal / us-east-2`；不使用 Team11 或 default。

本目录中的模板是本项目拟定的准备材料，**不是官方接口、官方标注、已完成作品或已测成绩**。所有对外材料提交前应删除未填占位符，并复核与实际实现一致。
