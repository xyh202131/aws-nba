更新：2026-10-09。作品名与当前前端一致。**可以演示本地工作台和离线 Agent；不能宣称完成云端模型分析、带标注 MP4 或正式提交。** 以下话术按真实状态使用，比赛完成后再补部署和成绩。

## 可直接使用的项目简介

COURTSIDE 把真实比赛视频、出手事件和有来源的官方数据放在同一条时间线上。观众可以回看关键画面、比较两次出手、检查每个数字的依据，并保存自己的复盘笔记。

当前包含两个视频回合与 41 条官方投篮记录。两次主要出手经过 AI 视觉核对和官方事件交叉检查；其余 39 条没有本地视频关联。蓝薄荷工作台提供回合、分析、档案和笔记四个区域。时间证据链只表明顺序和来源，不宣称建立了因果模型。

本地 Agent 会重新核验预览视频哈希、真实解码三个证据帧、校验结果并保存任务。默认回放既有观察，模型调用数为零。Bedrock 适配器已经写入代码，尚未做真实推理；最终目标仍是由 AgentCore 处理正式输入，经 CDK 定义的基础设施生成带标注成片并通过 CloudFront Web 展示。

## 答辩准备

- 为什么考虑两个模型：一个观察、一个独立看相同原始帧复核，但改善程度还需同样本比较；若没有收益就保留单模型。
- 工程工作在哪里：目前已有素材哈希、真实抽帧、三种时钟分离、官方记录关联、字段校验、持久化、错误状态与证据交互；自动定位和视频渲染尚未完成。
- 数字从哪里来：官方逐次记录；派生均值标明公式，语义冲突隔离。模型不得填写缺失的官方引力或概率。
- 能否恢复轨迹：官方深度数据只有出手瞬间点位，本项目不提供逐帧跑动轨迹或因果引擎。
- 怎样复现：本地可按 README 运行；赛事重跑要等官方适配、云部署和绑定核实后给出证据。
