## 产品范围

真实比赛视频与可追溯数字是核心。「AI 作品」为默认入口，原有回合、投篮分析、数据档案和笔记保留；蓝薄荷视觉。上传素材使用动态 ID，时间轴、证据、解说与数据卡共用契约。本地完整 MP4、中文语音、字幕与 Web 播放下载已实现；不增加轨迹/因果产品。

用户当轮指令与根 AGENTS.md 决定授权；本需求不是云部署、付费调用或赛事评测授权。

## 数据验收边界

现有 41 条投篮与官方 PBP 时钟已关联，只有 2 条有本地视频，独立人工复核未做。原片合计 44.444 秒。xFG 是官方预期命中率，不是模型置信度、实际命中率或投篮难度的同义词。三张赛季统计表合计 620 条不能计为独立事件。

实际原视频事件协议见[字段字典](../../../data/processed/20261009/data-dictionary.md)；Agent 类型见 [shared/agent.ts](../../../shared/agent.ts)。原片标注单位毫秒，Agent 帧/观察单位秒。无歧义的组合键为比赛、球员与官方事件；没有完整参考事件列表不报告召回率。

不要求所有视频出现固定数量或类型的动作。身份依号码、场景及官方记录核对，不引入人脸识别模块。移除 v1 的 0.70 自动审核阈值、强制非空解释、双模型一致即正确等假设。

## 环境与正式提交

- 当前按用户明确切换使用赛事 nba / us-east-1，目标 414702114718 / NBAHackathonParticipantRole；CLI 与 SDK 已核验，禁止 default 或个人项目回退。nba-sso 登录区域为 us-west-2，业务区域仍为 us-east-1。

- 官方规则：AgentCore、CDK、CloudFront Web；Portal 已绑定私有库；已有 bootstrap 与 NBAHackathonParticipantBoundary。Lambda、Python、GPU 不是硬要求。
- 2026/10/10 18:00 发考试片，19:45 调优结束，20:00 前最后有效提交；提交间隔至少 1 分钟；链接覆盖 20:00–22:20。
- 不保留 v1 自拟的成片必须 1–10 分钟限制；保留完整考试片，编码/体积/语言以官方 sample 或通知确认。
- 现有测试结果、设计目标和官方要求分别记录；3 秒加载、10 分钟处理等未验证目标不写成已经达标或官方规定。
