# 蓝薄荷版功能扩展与验收

> 蓝薄荷首版验收快照；5 项测试和当时产物尺寸保持原记录。最新 Agent 阶段为 20 项测试，见[Agent 验收](AGENT_ACCEPTANCE.md)；当前状态见[执行方案](PROJECT_PLAN.md)。

日期：2026-10-09。对应用户反馈：“配色换一下，用蓝偏薄荷绿”“功能区太少”。

## 交付结果

配色已整体换成深蓝导航、浅冰蓝画布、薄荷绿重点与深青色文字，包含播放器、图表、按钮、弹窗、手机布局及站点图标。原有暖色主题不再用于当前界面。

主导航由两个工作区扩展为四个。新增功能使用本地已有的 41 条逐次投篮记录与两条视频，不生成缺失的模型结果。

| 区域         | 可执行操作                                                                      |
| ------------ | ------------------------------------------------------------------------------- |
| 回合概览     | 查看比分变化、官方记账时钟、本次 xFG、该球员本场命中与出手数；进入投篮分析      |
| 精细回放     | 出手前后约 3 秒循环、前进/后退 1 秒、暂停并标记当前视频时刻                     |
| 投篮分析     | 切换球员、筛选节次、选择逐次 xFG 柱、查看来源或回看片段、查看分节与出手方式分布 |
| 回合补充面板 | 样本命中率、平均 xFG、分节摘要、个人笔记入口                                    |
| 复盘笔记     | 添加时间点笔记、分类、编辑、刷新恢复、回到视频时间点、JSON 导出、删除与撤销     |
| 数据档案     | 保留 41 条记录的组合筛选、来源核对、视频跳转与导出                              |

## 八项设计复核

| 维度     | 本轮处理及检查结果                                                                         |
| -------- | ------------------------------------------------------------------------------------------ |
| 排版     | 统一标题、说明、标签与统计数字层级；桌面导航容纳四项，手机四等分；辅助文字加深             |
| 留白     | 概览、回放、解读、下方摘要明确分区；图表内部保留标尺和记录详情空间                         |
| 视觉层级 | 视频保持首要关注，薄荷色指向当前状态及主要操作；分析页先指标、再逐次记录、再分布           |
| 色彩     | 移除旧橙色与暖色背景；计算主文字、辅助文字、导航文字、按钮等关键组合对比度                 |
| 动效     | 保留轻量状态过渡与减弱动效规则；无自动播放音频，循环只有手动开启后运行                     |
| 微交互   | 选中图表柱显示记录，分节点击联动筛选；笔记保存反馈、空状态、删除撤销均可操作               |
| 响应式   | 四个工作区在 8 个宽度完成整页溢出检查；手机档案转卡片，长图表在自身区域横向浏览            |
| 原创性   | 自行设计品牌、工作区与蓝薄荷视觉系统；使用参考图的任务方向，没有复制 Team11 标识或示例指标 |

本轮可见的文字过浅、窄屏图表点击空间不足、分析页沿用回合球队标识等问题已修正。Awwwards、Webby Awards、FWA 是完成度参照，不代表获奖或外部认证；“没有明显可提升之处”只适用于本轮检查范围内未见明显阻断问题，不表示设计没有后续迭代空间。

## 实际验证

### 构建与数据计算

- `npm run build`：TypeScript 与生产打包通过。
- Prettier 检查：源代码、测试及项目配置通过。
- `npm test`：5 项通过，覆盖空样本、两名球员聚合、分节筛选、实际命中与 xFG 的区分。
- 最终运行代码产物：JS 292.87 kB / gzip 88.25 kB；CSS 53.68 kB / gzip 11.68 kB。
- `git diff --check`：通过；Windows 换行提示不属于代码错误。

| 实际核对场景        | 结果                                                                 |
| ------------------- | -------------------------------------------------------------------- |
| 阿门全场样本        | 18 次出手、8 次命中、44.4% 样本命中率、42.8% 平均 xFG                |
| 阿门第三节筛选      | 4 次出手、2 次命中、50.0% 样本命中率、57.0% 平均 xFG，4 根可选柱     |
| 弗拉格切换          | 重置节次，23 次出手、13 次命中、56.5% 样本命中率、47.6% 平均 xFG     |
| 未关联视频的事件 30 | 来源弹窗显示比赛 0022500701、Q1 10:04、xFG 51.8%，明确无本地视频关联 |

### 新增交互

- 创建临时笔记、保存、刷新、编辑、导出、回到视频时间点的完整路径通过。
- 导出的 JSON 实际落盘并解析，包含正确 schema、片段、时间、内容与分类。
- 笔记回看定位到 `train_002` 的约 18.035 秒；播放器获得焦点。
- 删除后空状态、撤销恢复均通过；只移除了本轮创建的临时测试笔记，交付时笔记库为空。
- 循环开启后，以 2 倍速跨越区间末尾，实际返回区间内继续播放；检查结束恢复暂停、1 倍速、关闭循环。
- 最新生产预览页面控制台无 warning/error 记录。

### 布局与颜色

四个工作区分别检查 320、390、720、768、1024、1280、1440、1920 像素宽度，共 **32 项**：均无整页横向溢出。记录见 [blue-mint-viewport-checks.json](design/blue-mint-viewport-checks.json)。浏览器滚动条使内容宽度小于视口宽度属于正常行为；手机逐次图表有意保留内部横向滚动。

关键颜色组合计算见 [blue-mint-contrast.json](design/blue-mint-contrast.json)：主文字对画布 12.98:1，辅助文字 5.00:1，深青强调文字 4.88:1，薄荷按钮深蓝文字 7.78:1。曾低于 4.5:1 的数处辅助文字已加深。该检查不是全站 WCAG 认证。

## 文件与边界

主要实现文件为 `src/App.tsx`、`src/Studio.tsx`、`src/analytics.ts`、`src/styles.css`、`src/studio.css`；统计测试在 `tests/analytics.test.mjs`。主题同时更新 `public/court.svg` 和 `index.html`。设计说明、README、当前验收及截图一并提交。

- 当前验收使用本机 Chromium 及视口模拟，没有真机 Safari / Firefox 兼容性结论。
- 浏览器存储拒绝或损坏分支经过静态检查，本轮未注入存储故障。发生错误时页面会提示临时保存并允许导出，不覆盖无法读取的旧内容。
- 笔记仅在当前浏览器与站点保存，不跨浏览器/端口同步；未实现笔记导入。
- 原有媒体加载/失败恢复的实测证据属于上一轮，本轮没有重复故障注入。
- 两条视频事件仍是 AI 视觉核对加官方事件交叉检查，未经过独立人工复核。
- 本轮没有 AWS 部署、付费模型调用、训练或平台评测。
