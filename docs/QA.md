# 前端验收与迭代记录

> 历史前端验收；当前计划见 [PROJECT_PLAN.md](PROJECT_PLAN.md)，最近一次工程验收见 [AGENT_ACCEPTANCE.md](AGENT_ACCEPTANCE.md)。功能采用与取舍见 [REFERENCE_RECONCILIATION.md](REFERENCE_RECONCILIATION.md)。蓝薄荷首版验收见 [BLUE_MINT_ACCEPTANCE.md](BLUE_MINT_ACCEPTANCE.md)。下方第 1–5 轮是更早版本的历史验证，旧界面与媒体故障截图只用于保留当时证据。

检查日期：2026-10-09。范围：回合工作台、数据档案、来源弹窗、JSON 导出及桌面/移动布局。

环境为 Windows、Codex 内置浏览器。首三轮使用开发页 `http://127.0.0.1:5173/` 并复验生产页；第 4–5 轮直接使用 `http://127.0.0.1:4173/` 的生产构建。本次没有使用外部浏览器自动化替代内置浏览器，不是实体手机测试。

## 迭代记录

| 轮次 | 发现                                                                 | 调整与复核                                                                                               |
| ---- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 1    | 主体层级清晰，但辅助信息偏小、部分灰色对比不足                       | 统一提高标签字号；主文字、次要正文和强调文字分别实算为 14.32、4.60、5.06:1；在柔和面板上使用更深灰绿文字 |
| 2    | 窄屏数据表中的绝对定位屏幕阅读器标签逃出滚动容器，页面宽度变成 495px | 给表格滚动容器建立定位上下文；320px 下整页滚动宽度 305px，表格内部仍可横向滚动                           |
| 2    | 解读页签缺少左右键切换；弹窗焦点返回需要明确控制                     | 增加 tablist 的左右/Home/End 键与 roving tabindex；原生 dialog 关闭后焦点回到触发按钮，实测通过          |
| 3    | 关键帧高亮使用统一阈值，无法准确跟随不同片段的书签                   | 改成读取该片段自己的关键帧时间，保留预览降帧容差                                                         |
| 3    | 档案页导出反馈没有说明范围                                           | 实际下载全部 41 条，反馈文字明确“全部 41 条投篮记录”；单片导出明确为当前回合                             |
| 3    | 设计图中不能带未获依据的注册商标标记                                 | 移除标记，保留原创球场 SVG 及品牌字标                                                                    |
| 4    | 手机部分标签只有 8–10px，播放器多个动作挤在一行                      | 主要中文标签提高至 11–14px；进度条独立成行，播放/声音/全屏为 44×44px，倍速为 48×44px；320px 无溢出       |
| 4    | 手机档案需要横向滚动才能读完一条记录                                 | 720px 及以下使用纵向卡片，事件、时钟、出手方式、结果、xFG、来源在同一卡片；桌面继续使用表格              |
| 4    | 从档案回看或从页面下方定位，视频可能留在视野外                       | 档案回看聚焦视频并滚入视野；“再看出手”也将播放器滚回可见范围                                             |
| 4    | 媒体等待没有明确反馈，全屏失败会遮盖画面                             | 添加加载提示；全屏失败改为非阻塞提示；全屏模式保留控制条                                                 |
| 5    | 全屏按钮名称不随状态变化、清除搜索后焦点消失                         | 监听 fullscreenchange，按钮切换为“退出全屏”；清除搜索或筛选后将焦点交还输入框                            |
| 5    | 搜索容器与输入框双重焦点框造成视觉噪声                               | 合并为容器的一层焦点框，保留输入框的程序化标签                                                           |

## 八个设计维度

| 维度     | 检查结果                                                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 排版     | 主标题、回合结论、xFG 数字构成三个层次；手机主要中文标签为 11–14px，正文 13–14px；小号品牌副标和装饰编号保留                               |
| 留白     | 视频优先，面板开放排列；不使用重复大卡片填满空白；移动端按阅读顺序重排                                                                     |
| 视觉层级 | 先视频，再动作观察，再指标与来源；缺失引力信息保留低调但清楚的状态                                                                         |
| 色彩     | 橙色用于动作与强调，炭黑承载内容；关键文字颜色对比已计算；未宣称整站 WCAG 认证                                                             |
| 动效     | 仅用于选择、悬浮、切换与反馈；减弱动态效果实测后，关键帧图像 transitionDuration 为 `1e-06s`                                                |
| 微交互   | 视频控制、倍速、原声、定位、图层、页签、来源、筛选、空状态、下载反馈均经过操作验证；新增清除焦点、全屏状态、加载失败与重试实测             |
| 响应式   | 第 4 轮回看页检查 320、390、720、768、1024、1280、1440、1920px 八种宽度，无整页横向溢出；档案额外检查六种宽度，手机卡片/桌面表格只显示一套 |
| 原创性   | 使用独立暖白体育编辑视觉、原创球场标志、真实训练素材；没有复制参考图的品牌、队伍或示例指标                                                 |

## 构建与数据检查

- TypeScript 严格类型检查、Prettier 格式检查和 Vite 生产构建通过。
- 生产预览 `http://127.0.0.1:4173/` 单独验证：视频 readyState=4，定位到 18.0347 秒，图片全部载入，观察字幕正常，页面无横向溢出。
- 第 5 轮最终 JS 产物 272.20 kB（gzip 82.76 kB），CSS 35.22 kB（gzip 8.27 kB）；媒体文件单独按需加载。
- npm 安装审计报告为 0 项已知漏洞（本次安装时的注册表结果）。
- 前端 41 条投篮记录逐字段与处理数据包一致；2 条视频事件的事件 ID 和 xFG 对应正确。
- 两个预览 MP4 完整视频解码成功，时长与原片相差小于 0.1 秒；6 张真实关键帧文件存在。
- 媒体哈希与 `media-manifest.json` 一致。
- 代码检查覆盖 React 事件同步、事件监听清理、下载 Blob URL 回收、无动态 HTML 注入、无凭据或本机绝对路径进入运行时数据。

## 未验证与未实现

Safari / Firefox、实体 iOS / Android、读屏器实机、原音轨主观听审、全屏在其他浏览器上的兼容性尚未全面验证。当前内置 Chromium 的全屏已实测；媒体等待、失败和重试已完成本地网络故障注入测试。全屏不受支持的提示分支只完成静态检查，没有人为修改浏览器 API 进行验证。

本轮未实现或声称完成自动视觉模型分析、逐帧轨迹、独立人工金标准、TTS、带标注 MP4 导出、AWS 部署、赛事接口适配或正式平台评测。
