## 动效分工

- 页头云层：单一装饰画布，使用原工作台配色与取景；速度倍率 0.32、最高 480×180 像素预算。离屏、后台、手动暂停与系统减弱动效均停止动画时钟。
- 导航：同一选中底板滑动，测量只发生于切换与尺寸变化；不持续轮询布局。
- 内容：复用 Kit 222ms 横向页面入场；视角数据切换 300ms 轻移淡入。
- 操作：卡片轻抬、缩略图微缩放、导入图标轻移、按钮按下与弹窗入场。视频画面上不叠加装饰动效。
- 降级：WebGL 不可用时保留静态银蓝渐变；装饰画布从读屏树隐藏。系统减弱动效关闭转场、位移和缩放，内容保持可见。
