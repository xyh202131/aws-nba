# 设计说明：在画面与证据之间

## 方向

参考图给出了合理的任务顺序：选择回合 → 看比赛 → 理解动作 → 查看指标。本实现保留这个核心路径，重新设计了视觉语言、信息密度和响应式结构。

选用暖白纸面、炭黑标题与球场橙，将视频作为第一视觉焦点。左侧片段栏类似体育杂志目录；中央是真实比赛画面；右侧以简短观察、出手结果和一项核心指标组织信息。没有复用参考图中的球队、Team11、示例百分比、模拟标注圈或已有品牌名。

“COURTSIDE · 深度赛场”为此版本拟定的前端品牌；标志用可复用 SVG 的球场线条构成，不使用注册商标标记。

## 完整界面与状态

1. **回合工作台**：已选片段、暂停出手画面、播放/暂停/结束、关键帧定位、图层开关、倍速/原声/全屏。
2. **回合解读**：观察文本、两分命中、逐次 xFG、本回合缺失指标、快速回看。
3. **数据依据**：官方时钟、画面时钟、视频出手约值、前后比分；明确三者边界。
4. **数据档案**：41 条记录，组合筛选、空结果、可回看片段、未关联记录的来源入口。
5. **来源弹窗**：定义、官方链接、观察限制；原生模态焦点管理。
6. **移动端**：两列紧凑片段选择 → 视频 → 关键帧 → 解读；720px 及以下的数据档案改为纵向卡片，桌面保留比较效率更高的表格。
7. **导出反馈与媒体异常**：真实 JSON 下载反馈、媒体加载失败提示和重试。

## 视觉规则

| 维度 | 决策 |
| --- | --- |
| 画布 | `#f7f6f2`，减少纯白长时间观看的刺眼感 |
| 主文字 | `#23251f`，与画布实算对比度 14.32:1 |
| 次要正文 | `#697360`，与画布实算对比度 4.60:1 |
| 橙色文字 | `#b9411e`，与画布实算对比度 5.06:1 |
| 动作重点 | `#df4d20` 用于图形、焦点、较大标题和开关；不作为细小正文的统一颜色 |
| 数字 | Bahnschrift / Arial Narrow / Helvetica Neue 回退，等宽数字用于时钟 |
| 中文正文 | 系统字体栈，包含 PingFang SC、Microsoft YaHei；没有外部字体下载 |
| 留白 | 桌面 24–40px 主边距，开放面板之间 22–34px；用分隔线替代层层卡片 |
| 容器 | 视频圆角 8px，轻量按钮/图片 4–7px，避免所有信息都套大圆角 |
| 影像 | 16:9 完整视频，不改变球场比例；姓名牌与指标避开主要出手点和原记分牌 |
| 图标 | 单一线性图标族，图标带可访问名称；装饰性标志不重复朗读 |

## 动效与微交互

- 片段卡片 2px 悬浮反馈，关键帧轻微放大；不让悬浮成为唯一操作入口。
- 导航下划线、开关位移、指标变化和弹窗淡入提供状态反馈。
- 视频默认暂停且静音；不自动开始播放、不使用滚动劫持、光标特效或持续背景动画。
- 尊重 `prefers-reduced-motion`；键盘焦点与已选状态独立于颜色和动效。
- 播放状态来自实际 HTMLMediaElement 事件，切换片段重置倍速、静音与定位状态。
- 手机端播放、声音、全屏为 44×44px，倍速为 48×44px；进度条独立一行，避免挤压时间和触控区域。
- 搜索只有一层焦点边框；清除后焦点回到输入框。档案中的回看同时定位并聚焦视频，底部“再看出手”会把画面滚回视野。
- 加载中、加载失败、重试和全屏不可用分别反馈，失败的全屏请求不覆盖正常视频。

## 参考与质量方法

用户提供的三张截图用于了解任务结构，没有照搬页面或使用截图作为成品背景。Awwwards、Webby Awards 与 FWA 作为审美和体验质量目标，不在页面中放置奖项徽标或获奖声称。

具体检查参考了 [Webby 官方评审维度](https://www.webbyawards.com/judging-criteria/)中的视觉、导航、功能、交互与整体体验。Awwwards 官方评估页本轮抓取超时，FWA About 页未返回可读正文，因而没有虚构其权重或给本项目套用“官方评分”。技术实现参考 [React 官方 useRef / 原生视频交互](https://react.dev/reference/react/useRef)。

本版本的自检与修改见 [QA.md](QA.md)，属于当前环境中的实际验证，不是获奖资格或跨设备认证。
