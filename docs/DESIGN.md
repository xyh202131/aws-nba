# 设计说明：蓝与薄荷绿的比赛工作室

## 当前方向

2026-10-09 根据用户反馈替换上一版暖白与橙色。当前使用深蓝导航与侧栏、浅冰蓝画布、薄荷绿操作重点和深青色文字。保留真实比赛画面作为核心，但增加数据分析与个人复盘的可操作区域。

COURTSIDE · 深度赛场是本项目的原创前端标识。球场线条标志使用薄荷绿底色；没有复用参考图的 Team11、品牌、示例指标或战术标注。

## 四个工作区

| 工作区     | 实际可用内容                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------ |
| 回合工作台 | 两条片段、比分概览、视频控制、循环与 ±1 秒、标记此刻、回合时间轴、同步证据链、通俗/技术/复盘解读 |
| 投篮分析   | 样本统计、球员与节次筛选、逐次 xFG、分节和方式分布、同阶段两回合对照、来源与视频跳转             |
| 数据档案   | 材料状态、回合 JSON 核验与冲突报告、41 条记录的筛选检索、来源核对与 JSON 导出                    |
| 复盘笔记   | 时间点笔记、四种分类、编辑、浏览器本地保存、分类查看、回到视频时刻、JSON 导出、删除后撤销        |

视频下方的工具响应真实播放时间。“标记此刻”暂停视频并绑定当前时间；出手循环覆盖出手前后约 3 秒，并受片段边界约束。它不是原片逐帧定位功能。

## 参考功能的综合取舍

基于用户提供的 Reality5 界面，采用时间轴、证据关联、分层表达、对照与资料核验的任务结构。真实输入不支持因果引擎，因此将因果图改为可追溯的时间证据链；不展示虚构的速度、距离、追踪点或因果置信度。原有关键帧合并进时间轴，旧右侧解读被证据链替代，下方重复的样本/笔记宣传卡收拢到各自工作区。完整取舍、输入契约和验证见 [REFERENCE_RECONCILIATION.md](REFERENCE_RECONCILIATION.md)。

## 响应式与动效

- 桌面四项导航横排；手机四等分导航，无需横向寻找功能入口。
- 手机回放控制使用独立进度条和大触控按钮。两条片段以紧凑选择区展示。
- 手机档案用纵向卡片；多次投篮图表保留自身横向浏览以保证每根柱的操作空间。
- 分析页在窄屏改为两列指标与纵向图表；笔记编辑器及卡片适应窄屏。
- 开关、导航、筛选与选中柱提供轻量反馈；尊重减弱动效设置，不自动播放声音。
- 笔记移除后保留撤销入口；存储失败时明确提示临时保存在当前页面，允许导出。

## 数据与能力边界

统计直接计算自本地已有的官方逐次投篮记录。样本命中率等于命中数除以出手数；平均 xFG 是逐次百分比的算术平均，不替代实际命中率，不推出模型准确率。仅两条事件绑定本地视频。

没有生成缺失的引力、轨迹或球场坐标；个人笔记不冒充 AI 推断，也不自动上传。当前没有模型调用、云部署或赛事评测。浏览器清理站点数据会移除笔记，导出可留存副本；不同浏览器/端口不自动同步。

## 质量参照与证据

Awwwards、Webby Awards 和 FWA 作为设计完成度参照，不声称获奖。使用用户参考图中的核心任务顺序，但重新设计配色、导航与工作区。

[Webby 官方评审维度](https://www.webbyawards.com/judging-criteria/)强调视觉、结构导航、功能、交互与整体体验。本轮坚持真实可操作模块，不增加无数据支撑的模拟图表。
