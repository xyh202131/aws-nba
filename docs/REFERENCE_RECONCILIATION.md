# 参考功能取舍与证据工作台验收

日期：2026-10-09。输入为用户提供的五张 Reality5 界面参考图；这些图仅作为功能参考，没有将其中的样本数值、因果结论或运行耗时当作本项目事实。

## 产品取舍

继续使用 COURTSIDE 蓝薄荷视觉与四个主工作区。此次重点是把回看、证据、解释连接起来；每个功能归入已有工作区，避免添加第五种顶层工作模式。

| 参考内容                         | 本项目处理                                 | 取舍依据                                                                                       |
| -------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| 视频与追踪球场                   | 保留真实视频                               | 当前有两条视频，没有球员坐标；不绘制假追踪点或模拟球场态势                                     |
| 事件时间轴                       | 与原有关键帧合并为回合时间轴               | 使用真实视频时间；定位按钮、关键帧、证据节点与播放进度共享当前阶段                             |
| 因果图与可信度                   | 改为“动作上下文—出手定位—结果与记账”证据链 | 目前只能支持画面与记录核对；连线只代表时间顺序，不代表因果成立                                 |
| 证据面板                         | 融入右侧证据链                             | 每个节点标明画面观察、视觉核对或官方记录，提供来源入口与时间说明，不再保留旧的重复解读面板     |
| 大众 / 专业 / 教练叙述           | 通俗解读 / 技术视角 / 复盘提问             | 三种表达使用同一组已收录事实，证据引用可跳回画面；复盘提问不冒充教练因果结论                   |
| 对比现实                         | 投篮分析内增加“两回合对照”                 | 按相同出手阶段对照真实关键帧与官方指标；不同场次不被包装为控制变量或反事实实验                 |
| 上传 JSON 与分析流程             | 数据档案内增加“核验回合 JSON”              | 支持文件选择和文本粘贴，真实执行解析、格式识别、字段对照；成功后打开已收录回合，不伪造自动分析 |
| 速度、距离、球员引力、因果置信度 | 不展示数值                                 | 缺少必要输入与模型验证，统一在证据边界说明中交代                                               |
| 旧版样本摘要与笔记宣传卡         | 收拢重复入口                               | 样本统计保留在分析工作区和概览入口；时间点笔记由播放器标记或复盘提问进入，笔记管理保留在笔记库 |

## 使用路径

1. **回合工作台**：回看视频 → 点时间轴或关键帧 → 右侧证据节点同步 → 阅读不同视角 → 点击引用回看或写笔记。
2. **投篮分析**：样本统计保持原流程；切到两回合对照 → 选择出手前 / 出手 / 结果 → 查看两张关键帧 → 打开完整回合。
3. **数据档案**：查看材料状态 → 核验本站回合 JSON → 处理不兼容或字段冲突 → 核验成功 → 导出报告或打开已收录回合。
4. **复盘笔记**：继续使用已有的本地保存、编辑、分类、回看及导出流程。

## 输入契约与能力边界

- 接受本站回合导出的 `internal_review_not_contest_schema` 格式；这是内部格式，不是赛事提交 schema。
- 文件或粘贴文本不超过 256 KiB；文本按 UTF-8 字节检查。输入只在浏览器处理，不发起模型或网络请求。
- 必须匹配已收录回合的身份、官方事件、xFG、时间、文字观察、来源、媒体路径及关键帧。冲突字段明确列出。
- 核验成功只允许选择本地已有回合，不把输入对象写入事实数据、不加载输入中的任意媒体地址、不修改本地快照。
- 未收录回合、追踪 JSON、笔记 JSON、投篮档案 JSON 均返回不兼容结果；不显示“事件检测完成”或模拟进度耗时。
- 三种解读是对现有资料的确定性整理，不是新增模型输出；出手时刻仍为 AI 视觉核对约值，未完成独立人工复核。
- 对照采用关键帧，不是双视频同步播放。xFG 相差 6.5 个百分点不用于评判球员优劣或推出动作因果。
