## 5. 多模态输入的工程约束

根据 [Nova v1 视频理解文档](https://docs.aws.amazon.com/nova/latest/userguide/modalities-video.html)：

- 支持一个视频；内联/base64 总 payload 必须在 25 MB 内，同区 S3 视频单文件可达 1 GB。
- Nova Lite/Pro 对 ≤16 分钟视频按约 1 FPS 采样；这不足以直接得到篮球快速动作的精确帧级时间。
- 应保留原片，单独生成分析副本；事件附近补充关键帧，时间校验使用原视频坐标。
- 文档的 token 表用于近似计费；Nova Micro 的目录实际仅支持 TEXT，不能因表格顺带列出名字就认定它能读视频。
- Nova Lite 官方模型卡没有声明原生 Structured outputs 支持，不能假设请求严格 JSON schema 就自动可靠；应使用提示/工具返回加本地字段、时间和来源校验。

本轮没有发送视频或图片给 Bedrock，没有接受第三方模型协议或触发首次订阅，也没有用 CountTokens/评估作业伪装为只读目录核验。
