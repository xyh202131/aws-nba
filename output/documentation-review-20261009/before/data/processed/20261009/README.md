## 来源与处理规则

- 官方公开页面：[弗拉格场次](https://china.nba.cn/game/0022500701)、[阿门场次](https://china.nba.cn/game/0022500491)、[Inside the Game](https://china.nba.cn/inside-the-game)。先前公开原始快照保留在 [public-nba](../../public-nba/20261009/README.md)。
- 比赛逐回合字段来自普通网页加载和节次切换产生的成功响应。新文件 [selected-pbp-fields.json](selected-pbp-fields.json) 是 8 个节次中这两名球员投篮记录的**字段摘录**，不是完整逐回合原始响应；保留原字段名和原数组索引，不保存签名或设备标识。
- 严格以 `game_id + player_id + official_event_id` 关联；事件号 433 在两场比赛均出现，因此不得单用事件号连接。
- 官方时钟来自逐回合 `cl`，原投篮接口的空 `gameClock` 仍保持空值。未改原始 JSON、原视频或上一轮核对证据。
- `value` 的逐次 xFG 取自官方投篮记录；仅乘 100 转成百分数，不把它换称为投篮难度或胜率。
- [games.csv](games.csv) 使用明确的主客队 ID：弗拉格场次独行侠客场 107–111 火箭；阿门场次火箭客场 104–110 独行侠。源 `matchup` 文本的主客顺序冲突保留在审计文件。
