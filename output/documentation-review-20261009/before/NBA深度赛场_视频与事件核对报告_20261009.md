- 画面显示火箭主场、DAL/HOU 记分牌，独行侠进攻球员穿深色球衣；出手球员号码及动作过程与本次官方记录相符。核对没有依靠人脸识别。
- 片段开始是第四节约 01:52，比分独行侠 103–107 火箭；突破至篮下上篮后，比分变为 **105–107**，时钟停在 01:34。
- [中国官网第四节文字直播](https://china.nba.cn/game/0022500701/play-by-play)记录 `evt=666`、`pid=1642843`、`period=4`、`cl=01:34`，独行侠得两分，客队 105、主队 107。
- 既有 `gpShot` 原始数据中同一比赛、球员与 `eventId=666` 唯一对应“突破挑篮”、`success=1`、`value=0.51`。文字直播的概括“上篮”和深度数据的细分“突破挑篮”不要求逐字一致。

## 本轮处理和证据

- 找到本机已安装的 **PyAV**，没有安装/升级工具；原先“未找到 FFmpeg 命令”并不代表无法本地解码。
- 两段视频分别完整解码 **1,291 / 1,371 帧**，与容器样本数相同；音频也完成解码，没有解码异常。音频尚未听审，未验收主观音质和音画同步。
- 生成每 0.5 秒抽样的 **90 张完整画面**；针对出手窗口另存 **95 张连续帧**，带帧号、PTS、时间基、毫秒时间和文件哈希。原视频 SHA-256 与原登记一致，原件没有改写。
- 原始公共接口直取曾返回 HTTP 400；本轮通过官网正常浏览页面成功得到逐回合数据，并从网页网络响应提取两条所需事件。未复制凭据或重放浏览器签名。NBA.com CDN 的两个备用请求返回 403，失败记录保留，不作为成功证据。
- 保存的是两条完整事件对象及所在原响应的索引，不是两节比赛响应的完整镜像。相关响应有 131 / 115 条事件，仅用于定位本次两条得分事件。
